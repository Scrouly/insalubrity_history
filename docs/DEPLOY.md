# Раздача «Истории по вредности» на компьютеры кадровиков

## Как это устроено

```
Сервер: \\сервер\папка\InsalubrityHistory\
    current\      <- актуальная сборка (её обновляете вы)
    current.old\  <- предыдущая сборка (для отката)
    install\      <- install.bat + InsalubrityHistoryLauncher.exe (для новых компьютеров)

Компьютер кадровика:
    %LOCALAPPDATA%\InsalubrityHistory\InsalubrityHistoryLauncher.exe   <- запускатель (ярлык ведёт на него)
    %LOCALAPPDATA%\InsalubrityHistory\server.txt                      <- путь к папке на сервере
    %LOCALAPPDATA%\InsalubrityHistory\app\                           <- локальная копия программы (обновляется сама)
    %LOCALAPPDATA%\InsalubrityHistory\launcher.log                    <- журнал запускателя
    %APPDATA%\InsalubrityHistory\                                     <- ДАННЫЕ пользователя:
        .env, month_overrides.json, hire_dates_override.json, backups\, crash.log,
        ui_settings.ini (размер окна, ширины колонок, свёрнутая панель)
```

Обновление заменяет только `app\`. Папка данных никогда не трогается, поэтому у каждого
кадровика свои настройки, свои ручные правки и свой вид окна.

## Вам: выпуск обновления

1. Внесите правки в код, поднимите номер в `src\version.py` (например, `1.0.0` -> `1.0.1`).
2. `scripts\build.bat` — прогоняет тесты (при ошибке сборка не начнётся), собирает программу
   `dist\InsalubrityHistory` и запускатель `dist\InsalubrityHistoryLauncher.exe`.
3. `scripts\publish.bat \\сервер\папка\InsalubrityHistory` — копирует сборку на сервер.
   Путь можно один раз записать в файл `publish_target.txt` в корне проекта.
   Если номер версии на сервере уже такой же, publish откажется (иначе клиенты не поймут, что есть новая).

Откат: на сервере удалите папку `current`, переименуйте `current.old` в `current`.
Запускатель обновляет при любом отличии версии, поэтому клиенты вернутся на старую
при следующем запуске.

## Новый компьютер кадровика (один раз)

Запустить с сервера `\\сервер\папка\InsalubrityHistory\install\install.bat`.
Права администратора не нужны. Скрипт скопирует запускатель, создаст ярлык
«Insalubrity History» на рабочем столе и запустит его: первый запуск скопирует
программу с сервера (с окном «Установка программы» и ходом копирования).

Затем в программе укажите папки DBF и RSV — они сохранятся у этого пользователя.

## Что происходит при запуске ярлыка

1. Запускатель проверяет `\\сервер\...\current\version.txt` и сравнивает с локальным.
   Если проверка затянулась (медленная сеть), появляется окно «Запуск программы...».
2. Версии одинаковы -> окно не показывается, сразу запускается программа.
3. Версии разные -> окно «Обновление программы» с процентом и числом мегабайт; копирование
   идёт во временную папку `app.new` и только после полной проверки меняется на `app`.
   Обрыв сети или сбой не ломает рабочую копию.
4. Если обновить не удалось, пользователь видит причину, а программа запускается в прежней версии.
5. Сервер недоступен -> запускается локальная копия без сообщений.
6. Если программа уже запущена, обновление откладывается до следующего запуска.

Если что-то пошло не так, смотрите `%LOCALAPPDATA%\InsalubrityHistory\launcher.log`.

## Обновление самого запускателя

Запускатель маленький и меняется редко. Он не обновляет сам себя: после его изменения
выпустите обычное обновление (`publish.bat` кладёт новый `InsalubrityHistoryLauncher.exe`
в `install\` на сервере), а на компьютерах закройте программу и запустите `install.bat` заново.

## Если сервер переехал

В `%LOCALAPPDATA%\InsalubrityHistory\server.txt` одна строка с путём к папке на сервере.
Поправьте её вручную или запустите новый `install.bat` ещё раз.
